# S.E.N.S.E. POLY — Tabbed Prototype V3

A touch-friendly standalone, Poly D-inspired browser synthesizer prototype. This repository tracks the **selected tabbed layout** (Prototype A).

## Try the prototype

Once GitHub Pages is enabled under **Settings → Pages → Deploy from a branch → main / (root)**, open:

https://holonav.github.io/SENSE-POLY/

## Included

- Five synth-control tabs and a keyboard visible in the synth workspace
- Dedicated sequencer workspace with **all 32 steps visible**
- Eight banks of eight pattern slots (64 saved patterns)
- Live tempo knob, persistent Play/Stop/PANIC transport, touch-focused rotary control handling
- Functional browser-based audio preview, pattern editing and local state

**Status:** Interactive interface/audio prototype, not circuit-accurate analog-modeling or a native Android app. Verify gesture handling and audio performance on a physical Samsung device.

Inspired by classic paraphonic synthesizer architecture and workflow; not affiliated with or endorsed by Behringer.
